# Product

## Register

product

## Users

A developer working alone. Runs it locally on a Mac while working, usually mid-task in another tool: they have a rough need in mind and wants a well-structured prompt to paste elsewhere. Sessions last a minute or two.

## Product Purpose

Prompt Forge turns a rough idea into a strong, ready-to-paste Claude prompt using three local Claude CLI agents: an interviewer asks a few multiple-choice gap questions, a drafter writes the prompt, a critic reviews it cold and the drafter revises once. Success = the user pastes the output somewhere else and leaves.

## Brand Personality

Workshop-quiet, precise, warm-metal. A small hand tool, not a SaaS product. No marketing energy.

## Anti-references

- SaaS dashboard clichés: hero metrics, card grids, gradient text.
- ChatGPT-clone chat UI. This is a single-shot forge, not a conversation.
- Cream/beige "AI default" body backgrounds.

## Design Principles

- One job on screen: input → output. Nothing else earns pixels.
- The output is the product; typography of the result matters most.
- Waiting (~60-90s) is part of the flow; make it feel intentional, not broken.
- Zero dependencies; everything inline in one file.

## Accessibility & Inclusion

Keyboard-first (⌘/Ctrl-Enter submits). Visible focus states. Body text ≥4.5:1 contrast. Reduced-motion alternative for any animation.
